# Electronics Network API
 
Проект реализует иерархическую модель сети по продаже 
электроники с админ-панелью и REST API для управления звеньями сети, 
их продуктами и контактами.

---

## Стек технологий

- Python 3.13+
- Poetry
- Django 5
- Django REST Framework
- PostgreSQL
- django-filter

---

## Установка и запуск проекта

### 1. Клонировать проект
```bash
git clone https://github.com/svetlana-kolesnikova/Network
cd electronics-network
```

### 2. Установить зависимости через Poetry
```bash
poetry install
poetry shell
```

### 3. Настроить переменные окружения
Скопировать файл [.env_sample](.env_sample) и заполнить переменные:
```bash
cp .env_sample .env
```
Заполнить необходимые переменные в .env
Для локального запуска PostgreSQL должен быть установлен и запущен.


### 4. Применить миграции
```bash
python manage.py migrate
```

### 5. Создать суперпользователя (опционально)
```bash
python manage.py createsuperuser
```

### 6. Запустить сервер
```bash
python manage.py runserver
```
Сервер будет доступен по адресу:
http://127.0.0.1:8000

## Модели проекта

### NetworkNode (Звено сети)

Иерархическое звено сети продаж электроники.
- name — название звена
- contact — контактная информация (OneToOne)
- products — список продуктов (ManyToMany)
- supplier — поставщик (ссылка на другое звено сети)
- debt — задолженность перед поставщиком (Decimal, 2 знака)
- created_at — дата создания
- level — вычисляемый уровень иерархии
- Валидация отсутствия циклических связей поставщиков

### Contact (Контакты)
- email
- country
- city
- street
- house_number

### Product (Продукт)
- name — название продукта
- model — модель
- release_date — дата выхода на рынок

### Админ-панель

В админке реализовано:
- Отображение поставщика как кликабельной ссылки
- Фильтр по городу
- Admin action: очистка задолженности перед поставщиком
- Просмотр всех созданных объектов

### Права доступа к API

Доступ к API имеют только активные пользователи
```bash
request.user.is_authenticated and request.user.is_active
```

## API Эндпоинты

Network Nodes — ViewSet

| Метод     | URL                | Описание                               |
| --------- | ------------------ | -------------------------------------- |
| GET       | `/api/nodes/`      | список звеньев сети (фильтр по стране) |
| POST      | `/api/nodes/`      | создать звено сети                     |
| GET       | `/api/nodes/<id>/` | получить звено                         |
| PUT/PATCH | `/api/nodes/<id>/` | обновить звено (debt изменять нельзя)  |
| DELETE    | `/api/nodes/<id>/` | удалить звено                          |

Фильтрация:
```bash
/api/nodes/?contact__country=Russia
```

### Особенности реализации

- Вложенные сериализаторы для Contact и Product
- Автоматическое создание контактов и продуктов при создании узла
- Запрет изменения поля debt через API
- Вычисление уровня иерархии узла
- Защита от циклических связей поставщиков
- Фильтрация по стране через django-filter
